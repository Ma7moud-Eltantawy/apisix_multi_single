# 📦 مساحة مخصصة للـ Infrastructure as Code (IaC Templates)

هذا المجلد مخصص لفريق الـ DevOps لإضافة أي أدوات أو ملفات أتمتة إضافية يحتاجونها، مثل:
- **Kubernetes / Helm Charts:** لنشر APISIX على K8s Clusters.
- **Ansible Playbooks:** لتهيئة السيرفرات وتثبيت Docker و Git وتحديث الإعدادات آلياً.
- **Terraform Modules:** لإنشاء الـ VPC ومجموعات السيرفرات في AWS / DigitalOcean / Hetzner.
- **GitOps (ArgoCD / Flux):** لربط السحب المباشر من المستودع.
